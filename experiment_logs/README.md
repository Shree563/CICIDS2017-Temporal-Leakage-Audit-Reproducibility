# Experiment logs

Plain-text records of the experiment runs behind the CIC-IDS 2017 / CSE-CIC-IDS 2018 / UNSW-NB15 / CIC-DDoS2019 analyses: counts, settings, library versions, per-condition results and the checks made against earlier runs. The large run files (`*.csv`, `*.parquet`, prediction dumps) are not included in this repository.

| File | Content |
|---|---|
| `table6-dedup-rerun-results.md` | Table 6 / Table 20 reruns after duplicate removal, benign-only detectors, E1-E7 detail |
| `within-window-ten-windows-results.md` | Ten within-window controls, Bot diagnostics, per-cell results |

These are working logs: later entries supersede earlier ones where they disagree, and the final-run log is the reference for the reported numbers.
